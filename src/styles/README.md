# styles — visual do app inteiro

| Arquivo | Para que serve |
| --- | --- |
| `colors.ts` | Paleta de cores (azul principal, laranja, vermelho, verde, fundos) |
| `fontFamily.ts` | Nomes das fontes Manrope |
| `textSize.ts` | Tamanhos de texto padronizados |

**Quando mexer aqui:** para mudar uma cor, fonte ou tamanho em **todas** as telas de uma vez.
Para mudar uma tela só, use o `styles.ts` dentro da pasta dela em `src/screens/`.
