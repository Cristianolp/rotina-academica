# components — peças reutilizáveis

Componentes usados em mais de uma tela. **Mudar um componente muda todas as telas que o usam.**
Cada pasta tem `index.tsx` (o que faz) + `styles.ts` (visual).

| Pasta | O que é |
| --- | --- |
| `ActivityCard/` | Card de atividade (completo e compacto) |
| `ActivityForm/` | Formulário de atividade (criar e editar) |
| `Avatar/` | Foto redonda do estudante |
| `Badge/` | Etiqueta colorida ("Urgente", "Em dia"...) |
| `Button/` | Botão padrão do app |
| `DisciplineCard/` | Card de disciplina (completo e compacto) |
| `DisciplineForm/` | Formulário de nova disciplina |
| `Header/` | Cabeçalho "Minha Rotina" no topo das telas |
| `Loading/` | Círculo de carregamento |
| `PhotoViewer/` | Foto em tela cheia |
| `StatusScreen/` | Tela de "carregando" ou de erro ao abrir o app |
| `SummaryCard/` | Card de resumo com número grande (Início) |
| `TabBar/` | Barra de abas inferior |
