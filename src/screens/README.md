# screens — telas do app

Uma pasta por tela. Cada pasta tem:
- `index.tsx` — o que aparece e o que acontece ao tocar
- `styles.ts` — visual (cores, tamanhos, espaçamentos, posição)

| Pasta | Tela |
| --- | --- |
| `Home/` | Início (dashboard com resumo da semana) |
| `Disciplines/` | Minhas Disciplinas (lista, busca e botão +) |
| `DisciplineDetails/` | Detalhes de uma disciplina e suas atividades |
| `NewDiscipline/` | Cadastro de disciplina |
| `Activities/` | Atividades e Prazos (lista com filtros e botão +) |
| `NewActivity/` | Cadastro de atividade |
| `EditActivity/` | Edição de atividade |
| `ActivityDetails/` | Detalhes de uma atividade (concluir, editar, excluir) |
| `Profile/` | Perfil do estudante (foto e estatísticas) |
| `Settings/` | Configurações (nome, curso, semestre) |

**Quando mexer aqui:** para mudar o que uma tela mostra ou como ela fica.
