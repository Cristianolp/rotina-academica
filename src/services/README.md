# services — comunicação externa

| Arquivo | Para que serve |
| --- | --- |
| `api.ts` | Todas as chamadas para a API do `backend/`. Descobre o endereço da API e transforma erros em mensagens legíveis |
| `photoPicker.ts` | Abre a câmera ou a galeria, recorta e comprime a foto de perfil |

**Quando mexer aqui:** para adicionar uma chamada nova à API ou mudar a qualidade/recorte da foto.
