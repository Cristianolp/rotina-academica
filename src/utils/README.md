# utils — funções de ajuda

| Arquivo | Para que serve |
| --- | --- |
| `date.ts` | Formata datas ("Hoje, 23:59", "24 Out"), calcula dias que faltam e aplica a máscara dd/mm/aaaa |
| `activityStatus.ts` | Regras das atividades: qual badge mostrar (Urgente, Próxima...), cores das prioridades e a dica de estudo |

**Quando mexer aqui:** para mudar quando uma atividade vira "Urgente" ou como as datas aparecem.
